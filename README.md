# Projeto Laravel Breeze - Povoamento de Banco de Dados

Este projeto contém a implementação de Seeders para povoamento inicial da base de dados.

## Etapas de Construção e Execução

1. **Criação das Seeders e Factories:**
   ```bash
   php artisan make:seeder UserSeeder
   ```
2. **Configuração dos Dados:**

    - Implementada inserção pontual para ambiente de testes e geração massiva de 10 registros com User::factory().

3. **Execução das Migrations e Seeders:**
    ```bash
    php artisan migrate:fresh --seed
    ```
4. **Exportação da Base de Dados:**

    - O dump final foi exportado via SGBD no arquivo laravelseeder.sql.
